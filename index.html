Everything You Need in a Smart Lighting System

A complete IoT solution combining hardware sensors, wireless connectivity, and intelligent automation for modern smart homes.

🚶

PIR Motion Detection

HC-SR501 Fresnel lens sensor detects motion up to 7 meters. Auto-activates lighting when motion is detected in dark conditions.

☀️

LDR Ambient Sensing

GL5528 photoresistor continuously monitors ambient light levels. Prevents unnecessary lighting during daylight hours — saving energy.

📶

BLE Wireless Control

Web Bluetooth API integration for smartphone control. Connect HC-08 or HM-10 BLE module to control LEDs wirelessly from any browser.

🤖

Fail-Safe Automation

Arduino independently operates using PIR, LDR, and RTC even when website or Bluetooth is disconnected. No dependency on internet.

🎉

5 Intelligent Modes

Auto, Sleep (20% dim), Party (LED blink), Reading (80% stable), and Custom mode. Each mode optimized for specific use cases.

⚡

Energy Analytics

Real-time power consumption tracking with Chart.js visualizations. Daily, weekly, and monthly energy usage graphs with savings statistics.
